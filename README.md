# Звёздное превращение

Первый прототип прозрачного анимированного виджета для картинок.

## Как проверить

Открой `index.html` в браузере: пример с мышкой уже загружен. Через кнопку можно заменить её своей PNG-картинкой. Для PNG с прозрачным фоном сам предмет лучше читается.

Кнопка «Сохранить виджет» копирует HTTPS-ссылку с выбранной картинкой. После размещения страницы на GitHub Pages эту ссылку можно будет использовать как отдельный embed-объект в Genially. Встроенный режим убирает панель управления.

## Примечание

Это прототип: изображение в ссылке хранится в браузерном URL. Для крупных картинок ссылка может стать длинной; для готовой версии можно хранить картинки отдельными файлами в репозитории.
